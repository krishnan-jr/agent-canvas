Model Context Protocol (MCP) Server

Active • 25 Tools Available
Connect external AI agents (Claude Desktop, Cursor, Antigravity, OpenCode, Cline) directly to this canvas. The connecting agent receives full autonomous control to create projects, configure agents, wire routing edges, link skills, run workflow simulations, and export DAGs.
OpenCode manages MCP servers via the mcp block in opencode.json (project root) or ~/.config/opencode/opencode.json (global): 
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "agent-canvas": {
      "type": "local",
      "command": ["node", ""],
      "enabled": true
    }
  }
}
In Claude Code CLI, add via terminal command or project-level .mcp.json / global ~/.claude.json:
Terminal Command:
claude mcp add agent-canvas --command="node" --args=""
Or in .mcp.json:
{
  "mcpServers": {
    "agent-canvas": {
      "command": "node",
      "args": [""]
    }
  }
}
Add to ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows): 
{
  "mcpServers": {
    "agent-canvas": {
      "command": "node",
      "args": [""]
    }
  }
}
Add to your project .cursor/mcp.json or global ~/.cursor/mcp.json: 
{
  "mcpServers": {
    "agent-canvas": {
      "command": "node",
      "args": [""]
    }
  }
}
Add to global ~/.gemini/config/mcp_config.json or plugin plugins/<name>/mcp_config.json (supports STDIO and SSE serverUrl): 
{
  "mcpServers": {
    "agent-canvas": {
      "command": "node",
      "args": [""]
    },
    "agent-canvas-remote": {
      "serverUrl": "http://localhost:3000/api/mcp/sse"
    }
  }
}
For Cline (VS Code extension): cline_mcp_settings.json
For Windsurf (Codeium): ~/.codeium/windsurf/mcp_config.json 
{
  "mcpServers": {
    "agent-canvas": {
      "command": "node",
      "args": [""]
    }
  }
}
For remote agents or web hooks connecting over standard HTTP / Server-Sent Events:
SSE Stream URL: http://localhost:3000/api/mcp/sse
Message POST Endpoint: http://localhost:3000/api/mcp/message
